# Code of Conduct

## Our Pledge

Repo Ready Check aims to be a respectful, practical, and safety-conscious open source project.

Participants are expected to:

- Be respectful and constructive.
- Assume good intent while still addressing concrete problems.
- Avoid harassment, discrimination, personal attacks, or intimidation.
- Avoid posting real secrets, private keys, passwords, cookies, API keys, proxy subscription links, or private project data.
- Keep security reports focused on safe, fictional reproductions.

## Scope

This code of conduct applies to project issues, pull requests, discussions, documentation, examples, and other project spaces.

## Enforcement

The maintainer may remove harmful content, close issues or pull requests, or limit participation when behavior conflicts with this code of conduct.

For security-sensitive issues, follow [SECURITY.md](SECURITY.md) and do not include real credentials or private data.
